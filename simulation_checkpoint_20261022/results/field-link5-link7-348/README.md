#348 실제 파지 자세의 link5↔link7 비교

같은 실제348 저장 encoder 자세에서 공식 원본 collision STL의 FCL 간격은22.258mm, 당시 Isaac collision mesh의 간격은20.442mm입니다. 둘 다 접촉0입니다. SDK/Hand 좌표 불일치나 실제 원본 CAD 간섭이 원인이 아닙니다.

문제가 된 `right_link5_column_7_3`와 `right_link7_column_3_0`의 중심선 간격은26.444mm입니다. 두 원본 보수 캡슐 반경을 빼면4.514mm, 원래1mm 여유를 추가하면3.514mm가 남습니다. 오프라인 합성 설치 예제의 케이블 여유2mm를 양쪽에 각각 적용하면−0.486mm가 되어 거부됩니다. 추종 오차·시간 보간 팽창은 이 명목 비교에서0입니다.

따라서 이 특정 거부는 보수적 캡슐과 케이블 여유의 조합에 의한 것입니다. 실제 현장의 케이블 여유가 검증됐다는 뜻이 아니며, 여유를 자동으로 줄이거나 link5↔link7 예외를 추가하지 않았습니다. 원래20mrad 설정 및 UNKNOWN 거부는 유지됩니다. 실제 encoder q와 원본 actor frame은 평가에만 쓰였고, 명령·제어 경로에 재생하지 않았습니다. 새 카메라·파지·자세 탐색이나 실제 하드웨어 호출도 없습니다.

`diagnose.py`는 고정577 패키지의 원본 STL·캡슐과348 기록이 필요합니다. `result.json`에 원본 파일 해시·시간·최근접점·모든 여유 항목을 기록했습니다. 밀봉 패키지는 수정하지 않았습니다.
