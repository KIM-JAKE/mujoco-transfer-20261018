실제 Isaac Sim/PhysX에서 RGB-D 촬영부터 링2개·핀1개 파지·전달·삽입·고정·손 철수와 유지 확인까지 **272.89456초**에 통과했습니다. 시뮬레이션 시간52.84375초이며20/30초 목표는 미달입니다. 최신 코드는 이 기준 배치 한 사례만 전체 확인했으며 PLUS/MINUS 일반화나 반복 성공률은 검증하지 않았습니다.

작은 링은 기존 안정 파지 구간의 공개 엔코더·새RGB-D·기존 접촉 조건으로 실제 파지 폭을 확인합니다. 기존 유효기간과 매 스텝 범위를 유지하며 명령 폭 자체를 바꾸거나 추가 대기/촬영을 넣지 않습니다. 고정 운반 명령과 검사 결과는 원래 범위 안에서 재사용하고 집기/진입 보정과 현재 상대 팔·폭·완료 부품 검사를 유지합니다.

GPU2 충돌 서비스는 실제 production dispatcher가 바이너리를 선택하는 `pair-binary.sock` 별칭으로 연결했습니다. 완전히 동일한 변환 인덱스 행만 중복 계산을 제거하며 원래 커널 바이트·형상·1mm 기준·float64는 같습니다. 판정 불확실·서비스 오류는 원래 CPU 검사로 돌아가므로 CPU 검사 전체를 없앤 것이 아닙니다. GPU3는 카메라/인식에 사용했습니다. 별칭은 `pair-exact-dedup.sock`을 가리키는 상대 symlink이며 두 서비스의 고정 소스·모델·설정은 `service-sources/`에 있습니다.
