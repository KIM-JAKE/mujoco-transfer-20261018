# RGB-D 위치 변경 시험450: 세 부품 전체 성공

원래 고정 배치에서 큰 링 초기XY를(+10,−10)mm, 작은 링을(−10,+10)mm 옮기고 각각0.04rad의 기울기를 준 뒤 원래 물리 정착 과정을 거쳤습니다. 초기 변형은 장면 초기화에만 사용하며 컨트롤러에는 전달하지 않습니다. 실제 RGB-D로 작은 링/큰 링을 분류·추정해 파지하고, 작은 링 전달·삽입 중 다음 큰 링을 집고 올린 뒤 큰 링·핀까지 완료했습니다. 부착/온라인 물체 이동은 없습니다.

**첫 촬영부터 고정 유지 확인까지244.98초 / 진행한 물리53.68초**입니다. 모든 촬영·인식·계산·동작 대기를 포함합니다. 영상은 동작1배속, 긴 대기CUT를 명시하며 원본 전체 시간을 표시합니다. 20/30초와 실기 전체 실행은 검증되지 않았습니다. 동시 작업 부하가 달라446/432와 통제된 성능 비교는 아닙니다.

## 저장 경로 적용 범위

작은 링 왼손720개 저장 명령을 새 진입49개 명령과 연결해 실행했습니다. 실제 고정 설비 검사3605건을 재사용했습니다. 두 저장 경로 증명 파일을 준비하는 데 합계3.08초가 걸렸으며 첫 촬영 전입니다.

**큰 링은 저장 경로를 재사용하지 않았습니다.** 카메라에서 얻은 원형 부품 좌표계의 축 주변 방향이 기존 기준과180° 달라 엄격한 파지 범위를 벗어났고, 원래 전체 계획/검사로 돌아갔습니다. 이 정상적인 fallback을 캐시 성공으로 계산하지 않습니다. 이후 연구 소스에서는 다른 방향의 원래 CAD를 별도로 사전 검증하며, 형상이 대칭이라고 가정해 좌표를 바꾸지 않습니다.

이 시험에는 초기 근접 RGB-D 재촬영, 전체 원래 검사 상태의 GPU 행렬 전송/분할, 손가락 폭을 보수적으로 포함한 GPU 양팔 검사가 들어 있습니다. 원래 fixed/self/held/placed 접촉 검사와 FR3/Hand 한도는 유지했습니다. 빈 왼손은 검증된 첫 주차 후보를315개 명령/물리0.65625초에 실행했습니다.

## 파일과 재현 범위

`code/`와`support-code/`는 실제 frozen 소스403개 및 정적 입력7개를 SHA-256으로 대조한 복사입니다. `exact-source-manifest.json`과 원래`frozen-source-manifest.json`을 함께 보존했습니다. `acceptance-summary.json`은 원래`pipeline-results.json`의 전체 성공·하드웨어 미검증·속도 검사·캐시 적용 범위를 요약합니다. 기록된 내부 물체 상태는 평가/영상용이며 인식·제어 입력이 아닙니다.

전체 CAD, 생성된 `native-roas-table-bin-retimed14` 장면, Isaac Sim, 기존bin-picking 의존 파일과 GPU 서버가 별도로 필요합니다. 연구 소스를 실기에 그대로 재생하는 실행기가 아닙니다. [기준446의 구조·모델 가정](../fixed-cache446-pass/README.md)과 [현장 도구 안내](../../../FIELD_RGBD_20261022.md)를 확인하세요. 핀 충돌 형상의 여유와 사진 기반 홀더·센서 형상 해석 등 실제 장비와의 차이는 그대로 남습니다.
