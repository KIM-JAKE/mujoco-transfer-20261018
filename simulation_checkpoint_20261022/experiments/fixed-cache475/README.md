# 475: 전체 작업 실패 기록

새 철수 대체 경로 구현, 기존 핀 보정. 링 두 개는 삽입·해제 단계를 지났지만 핀의 RGB-D 정밀 보정이 원래16회 한도 안에 수렴하지 않아 **핀 삽입 전에 정지**했습니다. 전체 성공이 아닙니다. **290.83초는 실패까지의 시간**이며 성공 주기 시간으로 사용하면 안 됩니다.

원래75µm 중심/3mrad 축/150µm 샤프트 기준과 하드웨어 제한을 유지했습니다.476에서도 마지막 중심78.6µm·축4.825mrad로 허용 범위를 벗어났습니다. 수정은 추가 시험 중이며 이 기록에 소급 적용하지 않습니다.

정확한 소스·입력·원본 명령·RGB-D 관측·오류를 함께 보존했습니다. `pin-precision-diagnostic-events.jsonl`은 같은 실행 로그에서 추출한 실제 보정 과정입니다.475·476은 원래 철수 경로가 통과하여 새 대체 경로가 물리적으로 실행된 사례는 아닙니다. 대체 경로는 별도 모델 테스트와 기존 실제 명령 검사로만 검증된 상태입니다.
