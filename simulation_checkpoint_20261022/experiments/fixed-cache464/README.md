# 464: PLUS 위치 변경, 전체 저장 경로를 고려한 왼팔 대기 자세

이전463에서 오른팔 저장 경로 중간이 왼손과 간섭했습니다. 이 실행은 왼팔 이동 전에 저장 경로 전체를 검사하고, 실제 대기 자세에 도착한 후 다시 현재 상태로 검사하여 끝까지 통과했습니다. 추가 검사 계산이 커서 빨라진 버전으로 소개하지 않습니다.

- 실제 Isaac Sim/PhysX 전체 작업 성공: `True`, RGB-D 파이프라인 성공: `True`.
- 첫 촬영부터 최종 유지 확인까지 **303.87초**, 물리 시뮬레이션 **53.84초**. 20/30초 목표는 달성하지 못했습니다.
- 첫 촬영 전 준비 **27.54초**. 이 시간은 위 작업 시간에서 제외되어 있으며, 냉간 시작 총시간을 작업 시간과 혼동하면 안 됩니다.
- 여러 작업을 병렬 실행했으므로 다른 실행과의 시간 차이를 독립적인 성능 측정으로 해석하지 않습니다.
- FR3/Hand 제한과 원래 충돌 기준 유지. 부품 부착·초기화 후 순간이동 없음. 실기 로봇 검증 없음.
- 정확한 소스·입력 `413`개: `exact-source-manifest.json`, `SOURCE_SHA256SUMS`. 원본 결과·명령·카메라 관측·물리 기록을 함께 보존했습니다.

[실제 기록 영상](../../media/fixed-cache464-variation-plus-all3-pass-excerpts-1x.mp4)은 실제 벽시계 기준 1배속 발췌입니다. 긴 대기는 CUT 카드로 표시하며 원래 전체 시간이 계속 표시됩니다. 렌더를 위해 기록된 장면 자세를 재생할 뿐, 제어에 실제 물체 좌표를 공급하지 않습니다.

[서버 재실행 안내](../../FIXED_CACHE_RUN.md)의 checkpoint 경로를 이 디렉터리로 바꾸세요. 전체 복원 CAD·생성 장면과 현재 GPU 서비스가 필요합니다. 현장 SDK 실행 준비와는 별개의 시뮬레이션 결과입니다. 모델·실물 차이와 아직 검증하지 않은 조건은 [공통 안내](../../../FIXED_FRONT_20261022.md)를 참고하세요.
