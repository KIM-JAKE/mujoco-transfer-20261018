# PLUS 저장 경로 수정 과정의 실패 기록

462: 현재 주차 위치에서 저장 경로 입구까지의 직결 구간이 Palm과 고정0670에 간섭해177.89초에 동작 전에 정지했습니다.

463: 원래 장애물 회피 경로로 입구까지 실제 통과했습니다. 그러나 저장 운반 전체를 현재 상대 팔과 검사하자RIGHT link7과LEFT 손끝의 원래1mm 여유를 만족하지 못해199.84초에 저장 운반 발행 전에 정지했습니다. 둘 다 전체FAIL입니다.

그 시점의3영역 코드로 PLUS 일반화를 검증했다는 뜻이 아닙니다. 성공한460 기준 위치·461 MINUS와, 원래 전체 계획으로fallback한450 PLUS를 구분해야 합니다. 충돌 검사·속도·힘 상한은 늘리지 않았습니다.

이후 [464](../fixed-cache464/README.md)는 전체 오른팔 경로를 고려해 왼팔 대기 자세를 정하고 실제 위치에서 다시 검사해 전체 작업을 완료했습니다. 이전462/463 실패 결과에 이 수정을 소급 적용하지 않습니다.

[473](473/README.md)은 추가 계산 최적화 버전470과 같은 소스로 실행했습니다. 이 경우에는 큰 링 해제 후 빈 오른손 철수 곡선이 고정 설비와 간섭해 동작 전에 정지했습니다. 저장 파지 영역 밖에서 원래 계획으로 돌아간 사례이며 전체 작업 성공이 아닙니다.
