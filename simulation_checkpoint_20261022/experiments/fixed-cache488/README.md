# 488: 작은 링 실제 파지 폭 수정 통과, 마지막 오른팔 철수 FAIL

전체 작업은298.05초에 마지막 오른팔 철수의 실제165mm 이격 기준에서 정지했습니다. 세 부품 삽입 단계는 수행했지만 마지막 철수·고정 유지 전체 판정을 통과하지 못했으므로 **전체 FAIL**입니다. 실제 거리160.727mm, 명령 경로 끝172.509mm였고 공개 SDK 엔코더상 마지막 관절이 아직 이동 중이었습니다. 기준을 낮추지 않습니다.

작은 링은 명령 폭59.02mm와 실제 물린 폭61.83mm의 차이를 다루도록 기존 안정 파지 구간에서 실제 엔코더·새 RGB-D·양쪽 패드 접촉을 확인했습니다. 별도 대기/촬영을 추가하지 않았습니다. 기존 0.25초 유효기간·손가락 편차·실제 매 스텝 속도 범위를 유지하며, 본 실행에서146개 기존 파지 샘플과4108개 공개 엔코더 행이 전부 해당 구간 안이었습니다. 삽입/클램프 뒤 해제 시 바인딩도 해제됐습니다. 상세 근거는 `small-binding-qualification/`에 있습니다.

GPU3 RGB-D 인식은58장 모두 기존3초 촬영→준비 기준을 통과했고 최댓값1.016초였습니다. 하지만 충돌 서비스의 소켓 이름이 바이너리 선택 규칙과 달라22회 요청 모두 원래 CPU 검사로 돌아갔습니다. 따라서 본298초는 새 GPU 중복 계산 제거 효과를 검증한 시간이 아닙니다. 실제 잘못된 설정은 원본 결과/설정에 남겼고, 이후 실제 production dispatcher를 통과한 수정 주소 증거는 `service-sources/collision-gpu2-exact-dedup/after-run-dispatch-correction/`에 분리했습니다.

기존 FR3/Hand 한도·힘·질량·마찰·충돌 기준은 유지합니다. 부품 attachment나 초기화 뒤 teleport는 없습니다. 실제 로봇 시험은 하지 않았습니다. 정확한421개 소스/입력, 외부 서비스의 고정 소스·모델과 측정 프로파일을 함께 보존합니다.
