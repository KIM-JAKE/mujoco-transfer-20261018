# 468: 작은 링 오른손 전달 경로 재사용

기준 위치에서 링2개·핀1개 전체 작업과 RGB-D 파이프라인을 통과했습니다. 작은 링을 집은 현재 자세에서 저장 경로로 들어가는 구간과 최신 전달 목표로 나오는 구간을 새로 만들고, 가운데1068명령은 그대로 재사용했습니다. 실제 SDK형 엔코더·양팔·양쪽 손가락 폭·보유 물체를 원래 전체 검사에 통과시킨 뒤 움직였습니다. 저장 경로가 막히면 움직이기 전에 원래 경로로 돌아가 검사합니다.

- 첫 촬영부터 최종 유지 확인: **269.17초**, 물리 시뮬레이션 **44.78초**. 최초 준비104.51초는 별도입니다.
- 작은 링 오른손 전달 경로에서 고정 형상·자기충돌·보유 부품 증명 각각5345회 재사용, 변경 구간은280회 원래 검사.
- 전달 직전50ms 이상 명령 공백은 기존460의23.01초에서13.14초로 관측됐습니다. 이는 카메라·다른 작업의 부하 등이 섞인 관측치이며 통제된 속도 벤치마크가 아닙니다.
- 추가한 큰 링 운반 전 전체 경로 검사 비용 때문에 **전체 시간은460보다 늘었습니다**. 이를 해결하기 위한 세밀한 검사지점 사전 저장과 GPU 양팔 검사 묶음을 별도 시험 중입니다.
- FR3/Hand 제한·충돌 여유 유지, 부품 부착/초기화 후 순간이동 없음. 실기 미검증,20/30초 목표 미달성.

정확한 소스·입력415개와 원본 명령/관측/결과를 함께 보존했습니다. [재실행 안내](../../FIXED_CACHE_RUN.md), [공통 범위·실물 차이](../../../FIXED_FRONT_20261022.md)를 확인하세요. 이 실행은 영상으로 대체한 동작이 아니라 실제 PhysX 접촉을 실행한 결과입니다.
