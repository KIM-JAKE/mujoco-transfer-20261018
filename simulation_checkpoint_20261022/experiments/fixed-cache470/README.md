# 470: 세밀한 저장 검사지점과 양팔 GPU 검사

기준 위치에서 실제 PhysX 파지·양손 전달·링2개·핀1개 삽입·고정 전체 작업을 통과했습니다. 첫 촬영 이후259.27초, 물리48.31초이며20/30초 목표 미달성·실기 미검증입니다. 첫 촬영 전 준비는 별도로 원본 결과에 기록합니다.

원래1416개 큰 링 경로 명령은 바꾸지 않고, 원래5mrad 간격 검사의 모든1873개 샘플을 포함하는1864개 중복 제거 지점을 사전 검증해 저장했습니다. 새로운 현재 파지·영역·폭·고정 모델이 맞을 때만 재사용하고 모든 동적 검사는 유지합니다. 미래 경로 검사에서 고정/자기충돌/보유 부품 증명을 각각9365회 재사용했고 누락된 검사지점은0개였습니다. 왼팔 대기 이동 중에는 모든 현재/명령 오른팔 자세와 양쪽 폭 조합을 기존 GPU 검사로 묶었습니다.

후보 대기 자세의 미래 경로 검사 비용은464의26.38초에서14.94초, 대기 이동 구간은31.42초에서21.93초로 관측됐습니다. 다른 배치·명령·병렬 부하가 있어 독립적인 전체 성능 비교는 아닙니다. 실제 대기 위치에 도착한 뒤 현재 엔코더로 저장 경로 전체를 검사하는 기존 절차도 통과했습니다.

같은 코드로 위치를 바꾼 [473](../fixed-cache-entry-failures/473)은 링 해제 후 손 철수 경로의 원래 충돌 검사로 정지했습니다. 이 기준 위치 성공을 모든 위치의 반복 안정성으로 확대하지 않습니다. 정확한 소스416개와 원본 결과/명령/관측을 보존했으며 [서버 재실행 방법](../../FIXED_CACHE_RUN.md)을 참고하세요.
