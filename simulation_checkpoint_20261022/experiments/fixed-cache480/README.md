# 480: 저장 경로·RGB-D 보정·native Hand 전체 작업 성공

PLUS 위치 변경: 큰 링(+10,−10)mm, 작은 링(−10,+10)mm에서 실제 PhysX 파지·양손 전달·링2개와 핀1개 삽입·고정·손 철수까지 완료했습니다. 인식과 제어는 RGB-D+공개 SDK형 엔코더를 사용합니다. 전체 작업과 비전 파이프라인 모두PASS, 실기 로봇은 미검증입니다.

- 첫 촬영부터 최종 유지 확인: **254.28초**, 물리 시뮬레이션 **48.95초**.20/30초 목표는 미달성입니다.
- 첫 촬영 전 준비 **35.40초**는 별도입니다. 다른 작업과 병렬 실행한 시간이며 독립적인 속도 비교가 아닙니다.
- 양팔의 저장 명령과 증명을 재사용하고 최신 RGB-D 접근/진입 구간을 검사합니다. 현재 상대 팔·부품·손가락 폭·FR3/Hand 상한 검사는 유지합니다.
- 미래 왼팔 대기 후보는 전체 오른팔 저장 경로와 보수적인 GPU 양팔 검사로 비교합니다. 실제 이동 전 원래 전체 검사는 별도로 유지하고, GPU 불확실이면 원래 검사로 돌아갑니다.
- 작은 링의 새 파지 자세가 저장 영역 밖이면 실제 운반 승인 시 현재 공개 관측값으로 자기 부품 검사 증명을 한 번 만듭니다. 실패/영역 이탈은 원래 검사로 돌아갑니다. 이 계산 시간도 위 시간에 포함합니다.
- 핀 접촉 확인 후 기존 속도 프리로드 목표를0.0075→0.015m/s로0.3초 동안 올리고 새 RGB-D로 다시 파지를 확인했습니다. 힘 상한은기존30N/패드, 총60N으로 유지하며 **접촉 힘을 측정했다는 뜻은 아닙니다**. 마찰·질량·부품 부착·초기화 후 순간이동은 바꾸지 않았습니다.
- 위치·기울기 피드백을 분리하고 작은 내부 목표/제한된 이득 회복을 적용하되 원래75µm 중심/3mrad 축/150µm 샤프트 삽입 기준과16회 한도는 유지했습니다.
