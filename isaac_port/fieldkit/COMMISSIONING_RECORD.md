## 단계별 시험

아래 시험은 실제 현장 애플리케이션과 장치 어댑터가 구현된 뒤 진행한다. 제공 Python dry-run은 장치를 움직이지 않는다. 시뮬레이션 관절 경로를 실측 좌표·시작 상태에 대한 재계획 없이 재생하지 않는다.

| 단계 | 설정·관측 결과·로그 | 통과/미통과 |
|---|---|---|
| 연결 전 오프라인 CTest와 정책 검사 | | |
| 두 팔 상태 읽기·모드·좌우 매핑 확인 | | |
| TCP·하중·시작 자세·정지 수단 확인 | | |
| 실제 SDK 모델의 토크·변화율 검사 | | |
| 단일 팔 비접촉 저속 단계 | | |
| 링1 / 링2 / 핀 각각 파지·착좌·클램프·해제 | | |
| 실제 물체 위치 변경 후 관측·재계획·접촉 검사 | | |
| 버튼 신호와 유지 확인 | | |
| 양팔 구간 인터록·지연·한 팔 fault 시험 | | |
| 속도 증가 단계별 반복 시험 | | |

각 운동 시험에는 command fraction, 실제/명령 q·dq, desired torque, 통신 주기, I/O 시각, 접촉·fault 및 정지 이유를 기록한다. 공정 시간과 초기 이동·촬영·계획 시간을 분리한다. 아직 실행하지 않은 시험에 시뮬레이션 결과를 대신 적지 않는다.
