# 속도 이외에 현재 완주를 막는 것

2026-10-21에 읽은 상류 시뮬 시험 기록을 기준으로 정리합니다. 서로 다른 코드 버전·배치를 섞은 기록이므로 실패율 통계로 사용하지 않습니다. 실기 결과가 아닙니다. v128 43.533초 성공본은 별도로 보존하며, 새 실험이 나와도 이 패키지의 선택을 자동 변경하지 않습니다.

| 단계 | 기록에서 확인한 실패 | 뜻과 필요한 대응 |
|---|---|---|
| 바구니에서 집고 상승 | `No structure-clear grasp`, `No bin line IK loose_ring_lift` | 링을 보았더라도 손을 넣고 안전하게 들어 올릴 경로가 없을 수 있음. 겹침·바구니 벽·손목 도달 범위를 함께 검사하고 다른 후보를 고를 필요가 있음 |
| 양손 전달 | `Receiver approach disturbed held ring; closing is blocked`, `Fresh preclose RGB-D does not confirm opposing receiver pad geometry` | 받는 손의 접근으로 부품이 움직이거나 안정적으로 잡을 접촉 형상을 확인하지 못함. 실제 파지 상태 확인과 양손 접근 여유가 필요 |
| 전달·삽입 전 재관측 | `No directly measured annular face in transfer camera views` | 링의 면이 손바닥·손가락에 가려지거나 옆면만 보여 현재 자세를 측정하지 못함. 상부 바구니 시야와 별개인 면 관측 시야가 필요 |
| 삽입과 실패 복구 | `Image-corrected ... path hits structure`, `No fixed-structure-clear ... repick_retreat` | 실제 관측으로 보정한 경로에서 손바닥·손가락이 지그와 간섭하거나, 다시 잡기 위해 후퇴하는 경로가 없음. 삽입뿐 아니라 후퇴·재집기까지 가능한 파지를 선택해야 함 |

관련 시험 예: v141 삽입 시 손바닥 간섭, v142 상승 경로, v144 받는 손 접근으로 링 흔들림, v145 영상 보정 뒤 집기 간섭, v146/v154 전달 면 관측 실패, v152 작은 링 삽입 경로에서 손가락 간섭, v153 재집기 후퇴 경로 실패. v155에서는 seed445 한 배치가 42.705초 완주했지만, 다른 배치의 위 실패를 해결했다는 증거는 아닙니다.

기록을 종합하면 **처음 집을 수 있는 자세와 이후 전달·삽입·철수까지 가능한 자세가 일치하지 않는 것**이 공통된 설계 문제로 보입니다. 이는 실패 기록에 근거한 해석이며 각 실패의 물리 원인을 단독으로 입증한 분석은 아닙니다. 카메라가 볼 수 있는 면을 유지하는 파지·제시 자세, 다음 단계까지 가능한 경로 선택, 불안정할 때 실제로 내려놓고 다시 잡을 수 있는 복구 절차가 함께 필요합니다.

완주를 확보할 우선순위는 **현재 물체 상태가 잘 보이는 시야 확보 → 파지·전달의 안정성 → 삽입·철수까지 가능한 자세 선택 → 검증된 실패 복구**입니다. 단순히 동작을 느리게 하는 것만으로 가림이나 도달 불가·구조물 간섭이 없어지지는 않습니다.

[카메라 설치 가이드](CAMERA_INSTALLATION.md)의 관측 010/011, 023/025 비교는 같은 성공 실행에서도 관점에 따라 링 면이 가려졌다가 다시 보이는 예입니다. 실기에서는 카메라 모델·금속 깊이 품질·좌표 보정·센서 연결도 별도로 확인해야 합니다.
