# 준비한 기능과 현장에 남은 확인

| 항목 | 패키지에 구현한 것 | 실제 장치에서 확인할 것 |
|---|---|---|
| 독립 배포 | 오프라인 의존성·소스 빌드·무결성 검사, 기존 안정화와 분리 | 현장 OS/SDK/RT PC/USB 호환 |
| 무작위 링 인식 | v119·v128에서 해시가 같은 고정 검출기로 초기 링 위치 없이 RGB-D 검출, 이미지 안의 후보 분리·앞뒤 판별 | 실제 금속 깊이·반사·가림·해상도·시야 |
| 미인식 바구니 처리 | 별도로 실측한 적재물 포위 영역 전체를 장애물로 유지하는 선택 기능, 집기 타깃 생성 금지 | 포위 영역이 바구니와 돌출 적재물을 모두 포함하는지 확인 |
| 핀 인식 | 실측 홀더 주변 RGB-D CAD 정합, 파지 후 현재 이미지 재정합 | 홀더 보정·실물 영상 품질 |
| 동적 경로 | 실제 SDK 상태/FK/IK, 매 단계 경로 생성, 측정 형상·팔/손/물체/장애물·추종 오차 검사 | 측정 형상의 완전성, 실제 여유·정지·접촉 |
| 전달·삽입 보정 | 파지/전달 후 이미지+TCP로 손-부품 관계 재측정, 지그 목표를 TCP 목표로 변환 | 시야 확보·실측 공차·실제 파지/삽입 |
| 전체 실행 | 3개 집기·필요한 전달·안착·클램프·개방·철수·최종 유지 확인 | PLC 독립 신호·실제 동작·반복 성공률·시간 |
| 상류 결과 연결 | 해시 검증한 성공 스냅샷을 읽기 전용으로 가져와 비교 | 바뀐 검출기의 포팅·시험, 실기 설정 검증 |

검사 결과는 `reports/release-validation.json`에 기록합니다. Python/네이티브 시험과 이미지 재생은 실제 로봇 조립 시험이 아닙니다. 실제 장치는 내일 처음 연결하므로 `hardware_tested:false`입니다.

이전 v119 52.3011초 자료는 보존하고, 이번 버전은 v128 seed445 시뮬 한 배치의 43.5332초 성공 자료와 실행기 호환 프로필을 추가했습니다. 프로필 선택·실행 엔진·원본 자료의 해시는 각 단계 경로 증거에 연결합니다. 근거리 전달 분기 탐색과 시뮬 시간 배분·동시 작업 최적화 전체를 실제 로봇에 포팅했다는 뜻은 아닙니다. 여러 배치의 무작위 성공률·실기 완료·30초 미만을 입증하지 않습니다.

현장 전체 형상과 정지 시험을 검토하지 않은 동적 경로, 측정 없는 가짜 체크, 시뮬 관절 궤적의 실기 재생은 실행 경로로 허용하지 않습니다. 좁은 형상은 보수적 검사로 거절될 수 있습니다. 힘 제어 압입·실기 양팔 동시 운동·자동 에러 복구는 구현 범위에 포함하지 않습니다.

이전 `cycle`, `motion`, `handover` 도구는 측정·검토한 고정 경로를 쓰는 대안으로 유지합니다. 새 무작위 전체 흐름의 시작점은 `random-cycle`입니다.
